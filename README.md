I am Joey. IT Specialist at a custom cabinetry company in Pennsylvania, which in practice means I build most of the software the place runs on and still get called when the phones go down. The rest of my time goes to VitaTrack.

Mostly TypeScript on Cloudflare, and Swift when it is for Apple hardware. Python does the glue work. If I have to do something twice, the second time gets automated.
